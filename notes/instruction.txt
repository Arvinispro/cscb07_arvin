How to run seperate declaration and definition files on main.cc
1. Make sure no bugs in all files
2. use g++20 -c *.cc or g++20 -c file1.cc file2.cc ... filen.cc to turn them into object files
3. Run g++20 *.o -o <name-of-execuble> or g++20 file1.o file2.o ... filen.o -o <name-of-execuble>
4. ./<name-of-execuble>
